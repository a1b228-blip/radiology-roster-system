# RDQ 需求規格：放射診斷科 100% 離線 Web 一鍵排班系統

## 一句話任務
開發一套支援 **7 位** 放射師名單、**5 種** 機台資格（CT, MRI, DR, Angio, Mammo）、資深搭檔限制、勞基法 **11 小時** 休息間隔的單頁式離線 Web 排班系統。

## ✅ 已確認
- **純單頁可攜式離線 HTML (Vanilla JS + SheetJS + Vanilla CSS)** 介面，無需後端，瀏覽器開啟即用（Ⅰ & Ⅲ）
- 支援 **7 位** 人員名單及技能矩陣配置，含組長、資深、常規與新進等級（Ⅰ）
- 自動排班衝突原則：**優先滿足硬性限制**，遇缺口顯示**黃色警告單元格**而非中斷程式（Ⅲ）
- UI 支援 **雙視角**（放射師視角/機台視角）、**字級拉霸** (1.0~1.75)、**手動單元格點擊編輯與黃底標示**（Ⅰ）
- 支援 **原生 Excel (.xlsx)** 一鍵匯出與 JSON 設定檔導入匯出（Ⅰ）
- 納入 **手動改班 11 小時休息間隔即時警示**、**公平性統計報表**、**快照復原 (Undo/Redo)** 功能（Ⅳ）

## ❓ 假設（未確認，已採預設值）
- **公平性累計歷史** → 預設採 **當月重算 (zero)**，提供切換選擇。
- **預設週數** → 預設以 **當月完整週天數** 為產出範圍。

## ➕ 已採納（象限Ⅳ）
- 手動修改班表時，自動即時檢核 **11 小時休息間隔**與**資格違規**並彈出黃色警告框。
- 提供一鍵產出**公平性統計報表**（大夜數、假日班數、高階機台週數圖表）。
- 提供**班表版本快照與復原功能 (Undo / Redo)**。

## ❌ 排除項（明確不做）
- 後端資料庫及雲端 API 串接（堅守 100% 離線本地運作）。

## 📋 一段式需求規格
打造一套獨立離線的 **放射診斷科排班網頁系統**，主體採用 **index.html** 單一檔案架構，包含 **7 位** 放射師（**王組長**、**陳資深**、**林資深**、**張常規**、**李常規**、**趙常規**、**新人甲**）與 **5 大機台**（**CT**、**MRI**、**DR**、**ANGIO**、**MAMMO**）。系統需自動實作 **週輪調原則** 與 **CT/MRI 資深人員搭檔檢核**，並確保符合 **勞基法 11 小時休息間隔**。若人力不足，系統採柔性提示（**黃底警示格**）而非卡死。介面具備 **雙視角切換**、**字級縮放拉霸**、**手動點擊格子編輯與黃底高亮**、**即時違規警告**、**公平性統計報表**、**Undo/Redo 歷史快照**，並支援 **SheetJS 原生 Excel (.xlsx) 匯出**。

## ✔ 驗收條件
- [ ] 雙視角（放射師個人 / 機台檢查室）無縫切換且數據同步。
- [ ] 核心排班演算法可一鍵生成排班表，並自動滿足 CT/MRI 資深搭檔與 11h 休息間隔。
- [ ] 點擊單元格可手動修改班別並標示黃底，修改時自動跳出違規警示（若有）。
- [ ] 支援字級動態拉霸與原生 .xlsx 匯出，檔案能在 Excel 中正常開啟。
